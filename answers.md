# Відповіді на питання для самоконтролю

1. **Чому важливо вказувати user.name та user.email?**
   Ці дані записуються в метадані кожного коміту для ідентифікації автора змін в історії проєкту та прив'язки комітів до профілю на GitHub.

2. **Яка різниця між git pull і git fetch?**
   git fetch лише завантажує інформацію про нові зміни з віддаленого репозиторію без зміни локальних файлів. git pull завантажує зміни і одразу автоматично зливає (merge) їх у поточну локальну гілку.

3. Як скасувати останній коміт, не втрачаючи зміни у файлах?
   Виконати команду git reset --soft HEAD~1 — вона скасовує сам коміт, залишаючи всі змінені файли на місці та в індексі.
